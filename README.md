# Love King PRO Extension - Modos e Nota do Proprietário

Este repositório foi alterado pelo proprietário para operar em modo gratuito (branch `make-free`). As checagens de licença client-side foram desativadas nesta branch para permitir uso sem ativação.

Aviso: esta branch modifica a lógica que interagia com o servidor de licenças. Se o backend ainda rejeitar requisições por depender da `license_key` nos payloads, pode ser necessário ajustar o servidor ou remover o envio desta chave.

Para reverter, compare com a branch `main` e reverta as alterações relacionadas à flag `MAKE_FREE`.
